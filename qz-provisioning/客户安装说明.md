# QZ 打印安装说明

这份说明给现场安装人员或客户使用，用来完成针式打印机直打授权。

## 安装前准备

请先确认：

- 电脑已经安装好针式打印机驱动
- 电脑已经安装好 `QZ Tray`
- 当前电脑可以正常登录本系统
- 当前操作人有管理员权限，或知道管理员确认方式

## 安装步骤

1. 打开目录：
   [windows](D:/project/qz-provisioning/windows)
2. 找到文件：
   [install-qz-provision.bat](D:/project/qz-provisioning/windows/install-qz-provision.bat)
3. 双击运行，或者右键“以管理员身份运行”
4. 如果弹出目录选择框，选择 `QZ Tray` 的安装目录
5. 如果弹出 Windows 管理员确认，请点“是”
6. 等待脚本执行完成
7. 按提示关闭窗口

## 安装完成后验证

1. 回到系统
2. 打开任意可打印单据
3. 点击“打印”
4. 确认：
   - 不再反复弹授权确认
   - 打印任务进入实际针式打印机
   - 不是保存成 PDF

## 常见问题

### 1. 双击没有反应

请先打开 PowerShell，再执行：

```powershell
cd D:\project\qz-provisioning\windows
.\install-qz-provision.bat
```

### 2. 选不到 QZ 安装目录

请找到 `QZ Tray` 实际安装位置后再选择。常见默认目录：

```text
C:\Program Files\QZ Tray
```

### 3. 打印时变成保存 PDF

这通常是因为系统默认打印机不是针式打印机。请把 Windows 默认打印机切换为实际使用的针式打印机。

### 4. 安装后还是弹授权

请先关闭并重新打开 `QZ Tray`，然后再测试一次。如果还不行，请联系实施或开发处理。
