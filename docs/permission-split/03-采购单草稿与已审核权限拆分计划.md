# 采购单草稿/已审核拆分计划

## 目标

将采购单拆成“采购单草稿”和“采购单已审核”两套独立权限、菜单、列表页、表单页、打印页、打印模板和后端接口。

拆分后需要满足：

- 采购草稿权限只能进入草稿工作区，不能进入已审核工作区。
- 采购已审核权限只能进入已审核工作区，不能新增或编辑草稿。
- 草稿和已审核都支持打印，并使用各自独立的打印模板。
- 后端接口按状态隔离，草稿接口不能读取已审核采购单，已审核接口不能读取草稿采购单。
- 反审核只属于采购已审核侧。
- 旧 `erp-purchase:*` 权限保留用于迁移和兼容，但不再作为新页面的主权限。

## 权限设计

新增采购单草稿权限：

```text
erp-purchase-draft:view
erp-purchase-draft:add
erp-purchase-draft:edit
erp-purchase-draft:delete
erp-purchase-draft:approve
erp-purchase-draft:print
```

新增采购单已审核权限：

```text
erp-purchase-approved:view
erp-purchase-approved:copy
erp-purchase-approved:unapprove
erp-purchase-approved:cancel
erp-purchase-approved:print
```

旧权限保留但隐藏：

```text
erp-purchase:view
erp-purchase:add
erp-purchase:edit
erp-purchase:cancel
erp-purchase:approve
erp-purchase:unapprove
```

旧权限迁移关系：

```text
erp-purchase:view      -> erp-purchase-draft:view + erp-purchase-approved:view + erp-purchase-draft:print + erp-purchase-approved:print
erp-purchase:add       -> erp-purchase-draft:add
erp-purchase:edit      -> erp-purchase-draft:edit + erp-purchase-draft:delete
erp-purchase:approve   -> erp-purchase-draft:approve
erp-purchase:unapprove -> erp-purchase-approved:unapprove
erp-purchase:cancel    -> erp-purchase-approved:cancel
```

复制权限不从旧权限自动推导，除非业务明确希望老角色默认拥有复制能力。默认建议由管理员单独分配 `erp-purchase-approved:copy`。

## 前端拆分

当前已有采购草稿和采购已审核列表页雏形，继续彻底拆表单和打印。

新增或拆出 Vue 文件：

```text
ErpPurchaseOrderDraft.vue
ErpPurchaseOrderApproved.vue
ErpPurchaseOrderDraftForm.vue
ErpPurchaseOrderApprovedForm.vue
ErpPurchaseOrderDraftPrint.vue
ErpPurchaseOrderApprovedPrint.vue
```

允许抽公共逻辑，但页面入口必须独立：

```text
usePurchaseOrderForm.ts
PurchaseOrderItemsTable.vue
PurchaseOrderAmountPanel.vue
PurchaseOrderPrintRenderer.vue
```

`ErpPurchaseOrderDraft.vue` 职责：

```text
固定查询 DRAFT
显示新增、编辑、删除、审核、打印
不显示复制、反审核、作废
所有按钮使用 erp-purchase-draft:* 权限判断
```

`ErpPurchaseOrderApproved.vue` 职责：

```text
查询 APPROVED / CANCELLED 等非 DRAFT 状态
显示查看、复制、反审核、作废、打印
不显示新增、编辑、删除、审核
所有按钮使用 erp-purchase-approved:* 权限判断
```

`ErpPurchaseOrderDraftForm.vue` 职责：

```text
新增采购草稿
编辑采购草稿
保存草稿
审核草稿
打印草稿
审核成功后跳转采购单已审核详情
```

`ErpPurchaseOrderApprovedForm.vue` 职责：

```text
只读查看
复制为新草稿
反审核
作废
打印已审核采购单
不允许保存编辑
```

复制已审核采购单为草稿时，必须同时具备：

```text
erp-purchase-approved:copy
erp-purchase-draft:add
```

反审核成功后，单据回到 `DRAFT`，前端跳转到采购草稿编辑页或草稿详情页。

## 路由设计

新路由：

```text
/erp/purchase-orders
  redirect -> /erp/purchase-orders/draft

/erp/purchase-orders/draft
  component -> ErpPurchaseOrderDraft.vue
  permission -> erp-purchase-draft:view

/erp/purchase-orders/draft/create
  component -> ErpPurchaseOrderDraftForm.vue
  permission -> erp-purchase-draft:add

/erp/purchase-orders/draft/:id/edit
  component -> ErpPurchaseOrderDraftForm.vue
  permission -> erp-purchase-draft:edit

/erp/purchase-orders/draft/:id/print
  component -> ErpPurchaseOrderDraftPrint.vue
  permission -> erp-purchase-draft:print

/erp/purchase-orders/approved
  component -> ErpPurchaseOrderApproved.vue
  permission -> erp-purchase-approved:view

/erp/purchase-orders/approved/:id
  component -> ErpPurchaseOrderApprovedForm.vue
  permission -> erp-purchase-approved:view

/erp/purchase-orders/approved/:id/print
  component -> ErpPurchaseOrderApprovedPrint.vue
  permission -> erp-purchase-approved:print
```

旧路由兼容：

```text
/erp/purchase-orders/create -> /erp/purchase-orders/draft/create
/erp/purchase-orders/:id/edit -> /erp/purchase-orders/draft/:id/edit
/erp/purchase-orders/:id/print -> 根据单据状态跳到 draft 或 approved 打印页
```

## 后端接口设计

新增草稿接口：

```text
GET    /api/erp/purchase-orders/draft/page
GET    /api/erp/purchase-orders/draft/summary
GET    /api/erp/purchase-orders/draft/{id}
GET    /api/erp/purchase-orders/draft/{id}/print
GET    /api/erp/purchase-orders/draft/next-order-no
POST   /api/erp/purchase-orders/draft
PUT    /api/erp/purchase-orders/draft/{id}
DELETE /api/erp/purchase-orders/draft/{id}
POST   /api/erp/purchase-orders/draft/{id}/approve
```

新增已审核接口：

```text
GET  /api/erp/purchase-orders/approved/page
GET  /api/erp/purchase-orders/approved/summary
GET  /api/erp/purchase-orders/approved/{id}
GET  /api/erp/purchase-orders/approved/{id}/print
POST /api/erp/purchase-orders/approved/{id}/copy
POST /api/erp/purchase-orders/approved/{id}/unapprove
POST /api/erp/purchase-orders/approved/{id}/cancel
```

权限绑定：

```text
draft/page, draft/summary, draft/{id} -> erp-purchase-draft:view
draft/{id}/print                      -> erp-purchase-draft:print
draft/next-order-no, POST draft       -> erp-purchase-draft:add
PUT draft/{id}                        -> erp-purchase-draft:edit
DELETE draft/{id}                     -> erp-purchase-draft:delete
draft/{id}/approve                    -> erp-purchase-draft:approve

approved/page, approved/summary, approved/{id} -> erp-purchase-approved:view
approved/{id}/print                            -> erp-purchase-approved:print
approved/{id}/copy                             -> erp-purchase-approved:copy + erp-purchase-draft:add
approved/{id}/unapprove                        -> erp-purchase-approved:unapprove
approved/{id}/cancel                           -> erp-purchase-approved:cancel
```

状态约束：

```text
draft/* 只能访问 DRAFT
approved/* 只能访问非 DRAFT
draft approve 只能处理 DRAFT
approved unapprove/cancel 只能处理允许操作的已审核状态
copy 从 approved 生成新的 DRAFT
```

反审核规则：

```text
反审核只属于已审核侧
需要 erp-purchase-approved:unapprove
反审核成功后单据状态回到 DRAFT
```

旧接口短期保留：

```text
/api/erp/purchase-orders/page
/api/erp/purchase-orders/{id}
/api/erp/purchase-orders
/api/erp/purchase-orders/{id}/approve
/api/erp/purchase-orders/{id}/unapprove
/api/erp/purchase-orders/{id}/cancel
```

新采购页面不再调用旧接口。旧接口保留用于历史链接、外部调用和灰度兼容。

## 打印模板设计

新增打印模板单据类型：

```text
PURCHASE_ORDER_DRAFT
PURCHASE_ORDER_APPROVED
```

模板名称建议：

```text
采购单草稿打印模板
采购单已审核打印模板
```

模板使用规则：

```text
草稿打印只读取 PURCHASE_ORDER_DRAFT
已审核打印只读取 PURCHASE_ORDER_APPROVED
如果没有对应模板，提示“未配置采购单草稿打印模板”或“未配置采购单已审核打印模板”
不再混用旧 PURCHASE_ORDER 模板
```

打印日志：

```text
草稿打印日志要求 erp-purchase-draft:print
已审核打印日志要求 erp-purchase-approved:print
日志 docType 分别记录 PURCHASE_ORDER_DRAFT / PURCHASE_ORDER_APPROVED
```

## 菜单、角色权限页、迁移

菜单绑定：

```text
erp-purchase-draft -> erp-purchase-draft:view
erp-purchase-approved -> erp-purchase-approved:view
```

角色权限页：

```text
采购单草稿页面展示 erp-purchase-draft:*
采购单已审核页面展示 erp-purchase-approved:*
隐藏旧 erp-purchase:*
```

数据库迁移：

```text
插入新权限
插入新打印模板 docType 配置
更新菜单 permission_code
迁移旧角色权限到新权限
旧权限保留但 UI 隐藏
```

迁移要求幂等：

```text
权限不存在才插入
角色权限不存在才插入
菜单存在才更新
打印模板类型不存在才插入
```

## 验收标准

```text
只有采购草稿权限不能进入采购已审核
只有采购已审核权限不能进入采购草稿
采购草稿可打印且使用草稿模板
采购已审核可打印且使用已审核模板
反审核只在采购已审核侧出现
草稿接口不能读取已审核采购单
已审核接口不能读取草稿采购单
复制已审核采购单必须同时具备 erp-purchase-approved:copy 和 erp-purchase-draft:add
旧角色迁移后不丢失原有采购单访问能力
```
